# Image guide — Vedantstudiio

Images are referenced by `src` paths in the HTML files. Put images in this folder, then edit the matching `src="assets/filename.jpg"` in the relevant HTML file if you use another filename.

Suggested names:
- `hero.jpg` — home hero
- `smilecare.jpg` — SmileCare project preview
- `elementa.jpg` — Elementa Chemicals project preview
- `vedant.jpg` — About portrait
- `lab-type.jpg`, `lab-motion.jpg`, `lab-system.jpg` — first three Lab studies
- `lab-04.jpg` through `lab-08.jpg` — additional Lab studies

Use `.jpg`, `.png`, or `.webp` as you prefer; if you change the extension, update the HTML `src` too. The Lab design has eight photo-ready sections and can be expanded by duplicating an existing `<article class="lab-item">` in `lab.html`.
